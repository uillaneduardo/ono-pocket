Ono Pocket Design System

Documentação oficial da linguagem visual, componentes, estados e padrões de interação do Ono Pocket. Esta versão consolida o protótipo mobile-first com estética tecnológica pós-apocalíptica, foco em legibilidade e uso controlado de informação técnica.

Princípios

Texto primeiro

Texto, ícones e pequenas imagens devem carregar a maior parte da informação. O visual não deve esconder a lógica do jogo.

Tecnologia funcional

A interface deve parecer um sistema real de uma sociedade pós-apocalíptica, evitando neon excessivo e cyberpunk clichê.

Gerenciamento legível

Estados de jogador, Onos, estruturas e atividades precisam ser compreendidos rapidamente em tela pequena.
