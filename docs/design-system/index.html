Princípios

Texto primeiro

Texto, ícones e imagens pontuais carregam a maior parte da informação. O visual não deve esconder a lógica do jogo.

Tecnologia funcional

A interface deve parecer um sistema operacional de uma sociedade pós-apocalíptica, evitando neon excessivo e cyberpunk clichê.

Gerenciamento legível

Estados do jogador, Onos, estruturas e atividades precisam ser compreendidos rapidamente em tela pequena.

Components
